# EarnLink Rebuilt

Pages are now separated:
- signup.html — account creation
- login.html — login
- index.html — dashboard only
- tasks.html — task list
- task.html — individual task, 1-hour timer and proof upload
- verification.html — submissions/verification
- wallet.html — balance and M-PESA withdrawal UI

This version is a frontend prototype. Real authentication, video storage, verification, wallet credits and M-PESA withdrawals must be connected to a secure backend such as Supabase before launch.
